# G.O.D. contributor guidance

- Preserve the permanent separation between Saphira-A and Saphira-B.
- Treat `RootKernel` policy and authority as non-evolvable.
- Keep cells lightweight; a `DigitalNeuron` is not an LLM agent.
- Production buses must fail explicitly when no provider or organ is configured.
- Prefer deterministic behavioral tests and small typed standard-library modules.
- Every persisted model change requires a restart test.
