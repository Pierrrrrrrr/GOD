# Capability roadmap

This roadmap advances G.O.D. by evidence/competence gates, not calendar phases or module count. A milestone advances only when it demonstrates a complete causal capability while preserving the permanent architecture.

## Foundation — achieved/current

- Persistent Saphira-A and Saphira-B lineages with separate state.
- Root/owner authority, credential, permission, and audit boundaries.
- Explicit `ModelBus` and `BodyBus` production boundaries.
- Real observations and a separate verified-learning boundary.
- Typed capability demand, safe resolution, and honest capability gaps.
- Owner-governed capability leases.
- Safe Composite Organ self-construction from trusted operations, with independent proposals, isolated evaluation, sister audit, promotion, same-demand continuation, and restart restoration.

**Gate:** retain the existing deterministic and restart evidence for these properties; do not replace evidence with architectural labels.

## M1 — Durable Autonomous Goal Loop

**Prerequisite product gate:** the loopback-only `CORPORATE_SAFE` UI, explicit text/structured
model contracts, local-model discovery, bounded conversation failover, and honest unavailable
states must remain operational. These recovery mechanisms do not by themselves satisfy M1.

A goal survives interruption and continues through:

> understand → choose the next useful action or experiment → act → observe → verify → update → continue/replan → completion, honest block, or owner decision

**Gate:** demonstrate multi-step continuation and restart from durable state, bounded replanning, truthful completion/blocking, provider-failure recovery, and owner intervention through the production path.

## M2 — Verified Experience / Real Memory

Replace primitive relevance storage with durable structured experience containing provenance, prediction, evidence, outcome, prediction error, usefulness, and competence. A/B retain distinct developmental memory.

**Gate:** retrieval measurably improves later decisions; updates derive only from verified evidence; provenance and lineage survive restart without private-memory leakage.

## M3 — Capability Acquisition

Discover and evaluate external APIs, MCP tools, services, and resources through controlled acquisition boundaries beyond existing composites. Do not permit arbitrary host execution.

**Gate:** acquisition is permissioned, schema/scope validated, tested before trust, auditable, revocable, and demonstrably useful on held-out demands while failures remain capability gaps.

## M4 — Secure Code Organogenesis

Begin only after a genuinely isolated sandbox exists:

> candidate code → isolated execution → benchmarks → security audit → sister audit → shadow operation → promotion or rollback

**Gate:** prove host and credential isolation, resource/network limits, reproducibility, objective benchmark gain, audit integrity, and reliable rollback. Generated code never executes directly on the host.

## M5 — Distributed Compute / Cloud Metabolism

Treat local CPU, free-tier or low-cost compute, and remote workers as replaceable resources. Never assume unlimited free compute.

**Gate:** scheduling respects explicit budget, cost, privacy, reliability, and resource accounting; loss of a worker recovers without identity/state loss; measured benefit exceeds overhead.

## M6 — Economic Agency

Pursue legal, owner-governed economic objectives such as opportunity discovery, research, asset creation, outreach/automation, and measurable revenue, cost, and ROI.

**Gate:** every action stays within owner, platform, and legal constraints; costs and outcomes are evidenced and auditable; the system never hides actions or bypasses approval.

## M0 / Digital Ontogeny Lab — parallel research track

`DigitalCell`, morphogen fields, stigmergy, lateral inhibition, meristems, Physarum-like routing, regeneration, and related hypotheses remain separate from production. Each competes against simple baselines under identical evaluators.

**Gate:** only reproducible, measured winners with acceptable resource and safety behavior may be proposed for production promotion. Biological vocabulary or complexity is not evidence of competence.

The roadmap's measure is increasing demonstrated autonomous competence: goals completed durably, learning grounded in evidence, useful capabilities acquired safely, and resilience achieved within real resource and authority limits.
