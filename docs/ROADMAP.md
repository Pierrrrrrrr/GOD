# Roadmap

1. **Vertical slice (current):** dual persistent colonies, dynamic assemblies,
   verified plasticity, sparse workspace, typed goals, memory, candidate evolution,
   signed root audit, checkpoint/restart proof.
2. **Runtime hardening:** mailbox-backed asynchronous cell scheduling, schema
   migrations, event compaction, resource quotas, and broader fault injection.
3. **Grounded cognition:** permissioned model and organ adapters, richer verification,
   contextual memory indexing, measurable neuromodulator routing effects.
4. **Evolution laboratory:** sandbox benchmark suites, sister-colony audits,
   reproducible promotion gates, lineage visualization and rollback.
